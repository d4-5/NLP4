## Висновок
Stateful flow (потік зі збереженням стану) забезпечив значне покращення спостережуваності та надійності порівняно з простим ad-hoc пайплайном. 
Валідація виявила невідповідності схеми, а механізми fallback успішно відновили кілька кейсів. 
5-етапна оркестрація забезпечила стабільний формат експорту навіть для шумних або порожніх вхідних даних.
