## 1. Юзкейс
**Document Processing Flow (Потік обробки документів)**: інтелектуальний пайплайн, який приймає сирий український текст, визначає його призначення (Маршрутизація), витягує відповідні сутності (Виконання), перевіряє результат (Валідація) та експортує структурований JSON-запис (Експорт).

## 2. Етапи потоку (Flow Stages)
1. **Ingest (Прийом)**: Отримує сирий текст, генерує `case_id` та очищає вхідні дані.
2. **Route (Маршрутизація)**: Використовує `TriagerAgent` для класифікації вхідних даних у конкретну схему або маршрут.
3. **Execute (Виконання)**: Використовує `ExtractorAgent` для виконання фактичного завдання NLP на основі призначеного маршруту.
4. **Validate (Валідація)**: Дворівнева перевірка:
    - **Схема/Консистентність**: Програмна перевірка за допомогою `jsonschema`.
    - **LLM Review**: Агент `ReviewerAgent` перевіряє наявність галюцинацій та обґрунтованість (grounding) текстом.
5. **Export (Експорт)**: Форматує фінальний стан у стабільну, структуровану JSON-відповідь.

## 3. Структура стану (`FlowState`)
Об'єкт стану відстежує:
- Вхідні дані (сирі та очищені).
- Метадані маршрутизації (назва маршруту, причина).
- Артефакти виконання (сира відповідь LLM, розпарсений JSON).
- Статус валідації та виявлені проблеми.
- Деталі fallback (якщо використовувався ремонт або правила).
- Покрокову історію для аудиту.

## 4. Механізми Fallback
- **Repair Step (Етап ремонту)**: Якщо Reviewer виявляє незначні проблеми, викликається `RepairAgent` для їх виправлення.
- **Rule-based Fallback (Fallback на основі правил)**: Якщо ремонт через LLM не вдався, використовується екстракція на основі регулярних виразів (regex) для відновлення того, що можливо.
- **Safe Failure (Безпечна відмова)**: Якщо нічого не допомогло, потік експортує статус "failed" з частковими даними та прапорцем для ручного перегляду.

## 5. Покращення порівняно з Ad-hoc пайплайном
- **Спостережуваність (Observability)**: Кожен крок логується, що дозволяє чітко бачити, де стався збій.
- **Надійність (Reliability)**: Валідація та fallback гарантують дотримання схеми виходу, навіть якщо LLM видає некоректні дані.
- **Контроль**: Потік можна перенаправити або зупинити на основі логіки маршрутизації.
- **Стабільність**: Формат експорту є послідовним, що критично важливо для наступних систем.
