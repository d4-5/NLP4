## Обраний юзкейс
**Support Assistant (Помічник підтримки)**. Агент розроблений для допомоги команді підтримки шляхом попередньої обробки тікетів.

## Завдання агента
Агент повинен:
1. Класифікувати тікет.
2. Витягти релевантні сутності (ID замовлення, сума, дата).
3. Перевірити, чи достатньо в тікеті інформації для ідентифікованої категорії.
4. Сформувати фінальну відповідь або запитати відсутні дані.

## Реалізовані інструменти
1. `classify_issue`: Python-функція, що використовує зіставлення за ключовими словами.
2. `extract_support_entities`: Python-функція, що обгортає існуючу логіку витягу на основі правил.
3. `validate_support_fields`: Логіка для перевірки обов'язкових полів на основі категорії.

## Логіка прийняття рішень
Агент використовує промпт **ReAct**, який інструктує його спочатку подумати (**Thought**), потім діяти (**Action**) шляхом виклику інструменту, а потім спостерігати (**Observation**) за результатом. Йому суворо наказано використовувати `classify_issue` та `extract_support_entities` для кожного нового тікета.

## Логування
Кожен виклик інструменту логується у `docs/tool_logs_lab12.jsonl` з наступними даними:
- `timestamp` (часова мітка)
- `task_id` (ID завдання)
- `tool_name` (назва інструменту)
- `input` (вхідні дані)
- `output` (результат)
- `success` (успішність)
- `error` (помилка)

## Висновки
- **Переваги**: Агент набагато рідше "вгадує" ID замовлень або суми, оскільки покладається на інструменти на основі правил для витягу даних.
- **Надмірність**: Іноді агент викликає один і той самий інструмент двічі, якщо перший результат був для нього незрозумілим.
- **Галюцинації**: Без суворих інструкцій щодо зупинки, LLM схильна сама писати "Observation:", вигадуючи результати роботи інструментів.
- **Метрики**: Успішність роботи інструментів сильно залежить від надійності парсера дій та санітарії вхідних даних для інструментів.

## Наступні кроки
- Покращити парсер дій для обробки різноманітніших виходів LLM (наприклад, блоків JSON).
- Реалізувати складніший інструмент класифікації (наприклад, з використанням невеликої навченої моделі).
