# Короткий підсумок ЛР7
1. Назва задачі: класифікація домінантної мітки сутності для кожного `text_id` (`dominant_label`, або `NO_ENTITY`, якщо жодна сутність не домінує).
2. Базова модель з ЛР6: TF-IDF word(1,2) + Logistic Regression; `test accuracy=0.6147`, `macro-F1=0.2162`.
3. Протестовані SVM-моделі: LinearSVC word(1,2), LinearSVC char_wb(3,5), LinearSVC word(1,2)+char_wb(3,5), а також `class_weight=balanced` для найкращої SVM-конфігурації.
4. Найкращий фінальний результат на `test`: LinearSVC word(1,2)+char_wb(3,5) + `class_weight=balanced` з кастомним порогом для `PERIOD`; `accuracy=0.7249`, `macro-F1=0.4454`.
5. `char-ngrams` допомогли: найкращий `macro-F1` на валідації для char-моделі становив `0.3906` проти `0.3432` для SVM лише на word-ознаках (`+0.0474`).
6. `class_weight=balanced` допоміг: `macro-F1` на валідації зріс з `0.3906` до `0.4616`, а `macro-F1` на `test` з `0.3877` до `0.4332`; recall покращився для рідкісних класів `PERIOD`, `PCT` і `QUANT`, тоді як `TIME` залишився нестабільним, бо у валідації був лише один приклад.
7. Обраний поріг: one-vs-rest поріг для `PERIOD` встановлено на рівні `-0.6706` за результатами валідації, щоб максимізувати `F1` для рідкісного класу в логіці з пріоритетом recall; на `test` recall для `PERIOD` змінився з `0.1818` до `0.6364`, а `F1` для цільового класу з `0.2222` до `0.3889`.
8. Найчастіші типи помилок: шум / варіативність написання (`122`), недостатній контекст (`72`), хибнопозитивна сутність (`39`).
