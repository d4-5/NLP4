# Лабораторна робота 12

## Огляд
Ця лабораторна робота реалізує одноагентну систему для обробки тікетів підтримки. Агент використовує зовнішні інструменти для класифікації проблем, витягу даних та перевірки повноти інформації.

## Архітектура
- **Агент**: `SupportAgent` (у `src/agent.py`), що використовує Groq API.
- **Інструменти**: `classify_issue`, `extract_support_entities`, `validate_support_fields` (у `src/tools.py`).
- **Логер**: `ToolLogger` (у `src/tool_logger.py`), що зберігає дані у `data/sample/tool_logs_lab12.jsonl`.
- **Оцінювання**: `src/eval_agent.py` запускає 10 тест-кейсів та розраховує метрики.


## Метрики
- Успішність викликів інструментів (Tool call success rate).
- Середня кількість викликів інструментів на задачу (Average tool calls per task).
- Задачі з корисним використанням інструментів (Tasks with useful tool use).

## Висновки
Підхід з використанням інструментів (tool-grounding) значно зменшує кількість галюцинацій при витягу даних, оскільки знання агента базуються на надійних функціях, реалізованих на основі правил.
