# Лабораторна робота 9: Word Embeddings

## Опис
Натреновано моделі Word2Vec та FastText на корпусі текстів держзакупівель та новин.

## Основні результати
- **Корпус**: `processed_v2.csv`
- **Моделі**: Word2Vec, FastText (Skip-gram, size=100)
- **Найкраща модель**: FastText (краще обробляє морфологію української мови)
- **Цікавий кейс**: слово `тендер` має чітких сусідів `торги`, `закупівлі` в обох моделях.
