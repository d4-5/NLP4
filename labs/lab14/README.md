## Етапи потоку (Flow Stages)
1. **Ingest (Прийом)**: Очищення вхідних даних та ініціалізація кейсу.
2. **Route (Маршрутизація)**: Класифікація завдання та вибір відповідної схеми.
3. **Execute (Виконання)**: Екстракція сутностей за допомогою LLM.
4. **Validate (Валідація)**: Дворівнева валідація (JSON Schema + LLM Review).
5. **Export (Експорт)**: Генерація стабільного, структурованого виходу.

## Керування станом (State Management)
Об'єкт `FlowState` відстежує повний життєвий цикл запиту, включаючи проміжні результати, помилки валідації та дії fallback. Це забезпечує повну спостережуваність та можливість аудиту.

## Логіка Fallback
Система обробляє збої екстракції за допомогою:
- **LLM Repair (Ремонт через LLM)**: Цільові виправлення на основі відгуків рецензента (reviewer).
- **Rule-based Recovery (Відновлення за правилами)**: Екстракція на основі регулярних виразів (regex) для поширених сутностей.
- **Safe Failure (Безпечна відмова)**: Контрольоване завершення з частковими даними для ручного перегляду.
